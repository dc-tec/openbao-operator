Published 1 May 2026.

0.2.0 added steady-state read replicas and integrated them with upgrade, restore, restart, resize, and status
workflows. It also moved explicit restarts to `spec.runtime.restartAt` and tightened production admission.

## Before upgrading from 0.1

- Add a source-scoped `trustedIngressPeers` entry to clusters that use managed Ingress.
- Remove Hardened pod security-context overrides that weaken the runtime baseline.
- Grant the operator `read` on `sys/storage/raft/autopilot/state` before enabling read replicas on an initialized
  cluster.
- Apply the 0.2.0 CRDs before the controller or chart.
- Verify tenant onboarding, cluster conditions, and the read-replica pool after rollout.

{{< callout type="note" title="Historical compatibility" >}}
The 0.2.0 release gates covered Kubernetes 1.34 and 1.35 with OpenBao 2.5.3 as the primary target. Use the current
compatibility reference for a new deployment.
