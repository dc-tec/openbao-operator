Published 30 March 2026.

0.1.0 established the first stable pre-GA baseline after seven release candidates.

## Highlights

- manage OpenBao cluster bootstrap, self-initialization, and day-2 lifecycle on Kubernetes;
- support rolling and blue-green upgrades, backup, and restore;
- onboard namespaces for multi-tenant operation and support a single-tenant installation path;
- enforce a Hardened posture with admission, RBAC, and image-verification controls; and
- publish signed images, charts, release artifacts, SBOMs, and attestations.

The API remained `openbao.org/v1alpha1`; later pre-GA minor releases can contain migrations.

Open the [published GitHub release](https://github.com/dc-tec/openbao-operator/releases/tag/0.1.0) for artifacts and
the complete release-candidate history.
