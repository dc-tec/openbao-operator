Published 15 July 2026.

0.4.1 added OpenBao 2.6.0 compatibility on the 0.4 release line and stopped rendering the plugin directory when no
plugins are configured.

Use the rolling strategy for a pre-2.6 to 2.6.0 workload upgrade. The later 0.4.2 release adds the idle strategy
switch required by an existing pre-2.6 cluster configured for `BlueGreen`.

Open the [published GitHub release](https://github.com/dc-tec/openbao-operator/releases/tag/0.4.1) for artifacts,
signatures, provenance, and the complete change list.
